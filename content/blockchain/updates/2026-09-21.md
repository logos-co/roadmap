# Logos Blockchain Weekly Update - 2026-09-21

## `blockchain:highlights`

- **Node 0.3.0-rc.3 published for internal devnet testing** [release](https://github.com/logos-blockchain/logos-blockchain/releases/tag/0.3.0-rc.3)
- **Logos Execution Zone sharded program state merged** [#835](https://github.com/logos-blockchain/logos-execution-zone/pull/835)
- **Logos Execution Zone ciphertext padding merged: every private note is a uniform 512 bytes on chain** [#630](https://github.com/logos-blockchain/logos-execution-zone/pull/630)
- **Nimbos Proof of Quota zk verifier and queue-driven block processor merged** [nimbos#193](https://github.com/logos-co/nimbos/pull/193), [nimbos#194](https://github.com/logos-co/nimbos/pull/194)

## `blockchain:bedrock:research`

- `blockchain:bedrock:research:cryptarchia`
  - Hierarchical key management for one-time keys RFC opened, bumping the Wallet Technical Standard to 1.2.0 (in-review) [logos-lips#452](https://github.com/logos-co/logos-lips/pull/452)
  - Off-chain inscription bodies on Logos Storage RFC drafted: Logos Storage acting as a pseudo Data Availability network (draft) [logos-lips#454](https://github.com/logos-co/logos-lips/pull/454)

- `blockchain:bedrock:research:total-stake-inference`
  - Permanent forks observed on testnet 0.2.2 investigated: chain sync can fail to recover from a persistent fork despite repeatedly discovering the taller branch [#3577](https://github.com/logos-blockchain/logos-blockchain/issues/3577)

- `blockchain:bedrock:research:empowering`
  - Modelling framework built to assess whether tokenless newcomers can reach the Blend balance requirement before mined tokens unlock after one year, extended to multiple newcomers and capitalised competitors; numerical experiments identify leadership revenue and the finite mining pool as the key constraints [doc](https://app.notion.com/p/nomos-tech/EmPoWering-Analysis-of-Economics-3bd261aa09df80fcafc6c3cd3d0b6820?source=copy_link#3e1261aa09df802eb1f0e76dec1cd5b1)

- `blockchain:bedrock:research:permissionless-channel-sequencing`
  - User ownership of channel funds proposed: sequencer power over funds removed and handed back to users [doc](https://app.notion.com/p/nomos-tech/Preliminary-Research-User-Ownership-of-Channel-Funds-3dc261aa09df8038bf91d568b2c32040)
