# Logos Blockchain Weekly Update - 2026-04-27

## `blockchain:highlights`

- First stable Blend network: survived session transitions after 3 internal devnets ([rc.1](https://github.com/logos-blockchain/logos-blockchain/releases/tag/0.1.3-rc.1), [rc.2](https://github.com/logos-blockchain/logos-blockchain/releases/tag/0.1.3-rc.2), [rc.3](https://github.com/logos-blockchain/logos-blockchain/releases/tag/0.1.3-rc.3))
- Ledger fund-loss vector closed: NoteId uniqueness enforced, blocking a class of bugs where users could create notes with duplicate IDs ([RFC](https://www.notion.so/nomos-tech/RFC-Enforce-NoteId-uniqueness-335261aa09df807b9fe3c9bb9bd2c6db), [logos-blockchain#2579](https://github.com/logos-blockchain/logos-blockchain/pull/2579))
- Bounded leader-voucher memory growth in the node: replaced DynamicMerkleTree (linear growth) with Merkle Mountain Range (logarithmic) for voucher accumulation across wallet [logos-blockchain#2586](https://github.com/logos-blockchain/logos-blockchain/pull/2586), wallet-service [logos-blockchain#2587](https://github.com/logos-blockchain/logos-blockchain/pull/2587), chain [logos-blockchain#2588](https://github.com/logos-blockchain/logos-blockchain/pull/2588), and ledger [logos-blockchain#2585](https://github.com/logos-blockchain/logos-blockchain/pull/2585)
- Cryptoeconomics technical specs published in [Specifications](https://www.notion.so/nomos-tech/Specifications-345261aa09df80bf968cd21b1e3e9563?source=copy_link#345261aa09df8121b825d85f49c45ec0)
