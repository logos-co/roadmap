# Logos Blockchain Weekly Update - 2026-02-16

## `blockchain:highlights`

- Devnet stabilization: 0.1.2 release, config overhaul, IBD and NAT fixes
- Initial LEE Bedrock integration merged, now testing end-to-end
- Zone-SDK v0 API complete: sequencer, indexer, checkpoint, and self-healing support
- SQLite zone demo MVP ready
- DA sampling security: median time to first block built from unavailable data being accepted exceeds age of universe

## `blockchain:bedrock:research`

- `blockchain:bedrock:research:cryptarchia`
  - Continued refining Total Stake Inference (TSI) draft, addressing technical comments with updated sections and simulations [draft](https://www.notion.so/nomos-tech/Updated-Understanding-and-Improving-Total-Stake-Inference-Accuracy-via-Uncle-DAG-References-2fb261aa09df808784f5e7abaaea460a)

  - Began research on ZK checkpoints

- `blockchain:bedrock:research:tokenomics`
  - Proposed RFC for removing DA from TKE block rewards and fees specifications [RFC](https://www.notion.so/nomos-tech/RFC-Cryptoeconomics-Specifications-removal-of-DA-303261aa09df805cbee6f0805a8454f6)

- `blockchain:bedrock:research:da:sampling`
  - Computed joint probability of a node building a block from unavailable data, winning election, and the block being accepted by validators. Lower bound on median time to first such event exceeds age of the universe (epsilon=10^-4, f=1/30, 1-second slots) [analysis](https://www.notion.so/nomos-tech/Data-availability-DA-sampling-2d1261aa09df805facbcfd8184009928?source=copy_link#2f8261aa09df80619707e63cca81e857)

- `blockchain:bedrock:research:blend`
  - Iterating on Compressed Block Proposal RFC, expanded analysis to account for multiple collisions per transaction [RFC](https://www.notion.so/nomos-tech/RFC-Compressed-Block-Proposal-2e3261aa09df80a38df7eb9f14ddeb5e)
  - Reviewed Circom constraint optimization for comparisons paper, appended summary [doc](https://www.notion.so/nomos-tech/Comparisons-1fd261aa09df81feae1ff3e6612b92a0?source=copy_link#302261aa09df8067949aebef0d52fd31)
