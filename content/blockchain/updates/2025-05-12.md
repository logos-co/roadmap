# Nomos Weekly Update - 2025-05-12

## Nomos Bedrock

### Research

- Cryptarchia development:
  - [Fork Choice Rule](https://www.notion.so/Cryptarchia-Fork-Choice-Rule-14f8f96fb65c804986dff0565e8fdc54) updated to use a 2-phase approach: bootstrapping and online phases
    - Bootstrapping phase is uncommitted to any block, using density checks for resilience against misbehaving peers
    - Online phase rejects forks older than k, committing to the k'th block
  - [Causal Finality](https://www.notion.so/Causal-Finality-1dd8f96fb65c80a9aa29f0161c1d28c6) work focused on formalizing guarantees with happens-before relation
  - Bootstrapping and Synchronization [specification](https://www.notion.so/Cryptarchia-v1-Bootstrapping-and-Synchronization-1e58f96fb65c804aae85f84a2e94392d) redesigned to reflect new fork choice rules
    - Defines bootstrap fork choice rule enablement
    - Details block download methodology
    - Introduces bootstrapping from checkpoints using immutable block principles
- Mantle development:
  - [Mantle Specification](https://www.notion.so/Mantle-Specification-1ba8f96fb65c8076ba00ecff00e7a3a4) improvements with updated content, removing shielded notes
  - [Anonymous Leader Reward Distribution Protocol](https://www.notion.so/Anonymous-Reward-Protocol-for-Leaders-1ea8f96fb65c80aab2dfc2c8b0ef91a7) draft completed
  - [Service Reward Distribution Protocol](https://www.notion.so/Service-Reward-Distribution-Protocol-1ea8f96fb65c803187c2fdce4e2a8934) draft completed
  - [Proof of Quota Specification](https://www.notion.so/Proof-of-Quota-Specification-1c88f96fb65c80c78c20c7136e7987d8) rewrite in progress for performance realism
  - [Incentivizing Transaction Inclusion](https://www.notion.so/Incentivizing-Transaction-Inclusion-1ee8f96fb65c809eaf1eea8ffb13b76b) specification detailing private leader rewards
- Block processing framework:
  - [Block Proposal Construction, Validation and Execution Specification](https://www.notion.so/Block-Proposal-Construction-Validation-and-Execution-Specification-1a48f96fb65c8078b625dbd3a101a7bc) scope expanded with enhanced structure
- P2P Network improvements:
  - [Nomos P2P Network NAT Solution](https://www.notion.so/Nomos-P2P-Network-NAT-Solution-1d28f96fb65c80198b03f777be835967) specification finalized with missing diagrams added
- SDP impact analysis:
  - [Impact of Service Declaration Protocol on adversarial inference](https://www.notion.so/Impact-of-Service-Declaration-Protocol-on-adversarial-inference-1ec8f96fb65c8060a264cf433bdc3445) analyzing statistical implications
