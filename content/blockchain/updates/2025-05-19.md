# Nomos Weekly Update - 2025-05-19

## Nomos Bedrock

### Research

- Cryptarchia development:
  - [Cryptarchia v1 Protocol Specification](https://www.notion.so/Cryptarchia-v1-Protocol-Specification-7816b67600bb4aad93507723f06ac2e5) updated to check if a block is descendant from the latest immutable block and update chain maintenance logic to prune forks
  - [Cryptarchia v1 Bootstrapping](https://www.notion.so/Cryptarchia-v1-Bootstrapping-1e58f96fb65c804aae85f84a2e94392d) redesigned to align with explicit commits
  - [Causal Finality](https://www.notion.so/Causal-Finality-1dd8f96fb65c80a9aa29f0161c1d28c6) progress on formalizing guarantees with definitions finalized and structure section in development
  - [Block Times & Blend Network](https://www.notion.so/Block-Times-Blend-Network-1f38f96fb65c8001a724cad5a2c1e634) simulations completed to resolve questions about block times and parameters
- Consensus proof systems:
  - [Proof of Leadership Specification](https://www.notion.so/Proof-of-Leadership-Specification-1438f96fb65c80f6bb1adfeb73473f65) updated for the new public ledger
  - [Proof of Selection Specification](https://www.notion.so/Proof-of-Selection-Specification-1c88f96fb65c80b380f6f6bde8172403) rewritten with cryptographic details
  - [Privacy-Preserving Hybrid Consensus](https://www.notion.so/Privacy-Preserving-Hybrid-Consensus-1ec8f96fb65c8069b0b2e53ac2fd35c0) exploration of alternative PPoS designs for Nomos v2
- Mantle development:
  - [Block Proposal Construction, Validation and Execution Specification](https://www.notion.so/Block-Proposal-Construction-Validation-and-Execution-Specification-1a48f96fb65c8078b625dbd3a101a7bc) draft started, referencing validation and execution specifications from Cryptarchia and Mantle
  - [Mantle Specification](https://www.notion.so/Mantle-Specification-1ba8f96fb65c8076ba00ecff00e7a3a4) reviewed with updates in progress
- Economics:
  - [Block Rewards Specifications](https://www.notion.so/Block-Rewards-Specifications-1f38f96fb65c802abd39ef2ff3bf9d45) draft detailing reward requirements
  - [WIP: An Overview of Transaction Fee Mechanisms](https://www.notion.so/WIP-An-Overview-of-Transaction-Fee-Mechanisms-1f58f96fb65c802b9e2fdadaac6292a6) analyzing pros and cons of different approaches
  - [Impact of Service Declaration Protocol on adversarial inference](https://www.notion.so/Impact-of-Service-Declaration-Protocol-on-adversarial-inference-1ec8f96fb65c8060a264cf433bdc3445) analyzing statistical implications of knowing node stake

- Storage optimization:

- P2P network enhancements:

  - Planning implementation of NAT traversal state machine
- Membership service:
  - Implementation progress with [PR #1268](https://github.com/logos-blockchain/logos-blockchain/pull/1268)
- Transaction framework:

  - ActivityContract removal from SDP implementation in preparation
- Infrastructure improvements:
