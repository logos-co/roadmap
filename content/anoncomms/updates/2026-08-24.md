## Highlights

- An initial Rust implementation of the [Poseidon2 hash function has been drafted for Zerokit](https://github.com/vacp2p/zerokit/pull/437), working toward faster hashing for RLN.
- Cover traffic for the libp2p mixnet now applies a pre-send hold, with the mechanism [specified](https://github.com/logos-co/logos-lips/pull/403) and [implemented](https://github.com/logos-co/nim-libp2p-mix/pull/52) in nim-libp2p-mix.

## Establish libp2p mixnet

- [Research more advanced cover traffic generation techniques](https://github.com/logos-co/anoncomms-pm/issues/51)
  - achieved: applied a pre-send hold to cover transmissions ([spec](https://github.com/logos-co/logos-lips/pull/403), [implementation](https://github.com/logos-co/nim-libp2p-mix/pull/52))

- [Implement local reputation mechanism and research advanced DoS protection](https://github.com/logos-co/anoncomms-pm/issues/52)
  - achieved:
    - analysed internal security audit findings, created further tracking issues, and fixed [in-flight bookkeeping](https://github.com/logos-co/nim-libp2p-mix/pull/53)
    - added two integration architectures to the mix DoS protection spec
    - local reputation analysis: vetting does not help against a strategic adversary — the achievable compromise is set by the path structure
    - reviewed [PR 42](https://github.com/logos-co/nim-libp2p-mix/pull/42), [PR 403](https://github.com/logos-co/logos-lips/pull/403) and [PR 52](https://github.com/logos-co/nim-libp2p-mix/pull/52)
  - next:
    - continue local reputation work assuming a trusted set of nodes
    - rebase the stake-weighted RLN spec
    - implement rate differentiation

## Decentralised Oracle Network

- [Implementing Oracle Zone](https://github.com/logos-co/anoncomms-pm/issues/57)
  - achieved:
    - experimented with precompiled RISC0 methods that may achieve 18x fewer transaction cycles for signature verification, allowing more signatures in a single transaction ([PR](https://github.com/sydhds/lon_poc/pull/3))
    - experimented with creating Logos Blockchain transactions on the public testnet by opening new channels for each indexer ([report](https://github.com/seugu/lon_oracle_zone_bench/blob/bedrock-channel-test/report.md))
    - reviewed the [RISC0 optimisation PR](https://github.com/sydhds/lon_poc/pull/3) and the [dispute mechanism spec PR](https://github.com/logos-co/logos-lips/pull/390)
    - completed a basic implementation of the oracle register and oracle prices contracts
  - next:
    - improve the experiments with malicious attempts
    - live testing of the oracle node zone and indexer
