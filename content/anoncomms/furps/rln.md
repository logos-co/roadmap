# Logos Generalised RLN FURPS

## Functionality

1. An RLN membership allocation service can register ID commitments on behalf of third parties
2. The RLN membership allocation service has a pluggable authentication mechanism to determine eligibility for membership
3. Logos modules can use the service to obtain adequate registered RLN identities without interacting with the contract
4. The Logos module IP is not linkable to any of its on-chain RLN identities

## Usability

1. The RLN membership allocation protocol is published in a specification
2. Logos Messaging and Chat SDK can use the service to obtain RLN memberships
3. The RLN contract is implemented for LSSA
