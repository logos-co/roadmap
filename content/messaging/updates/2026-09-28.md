## Highlights
<!-- Please Add the team weekly highlights here -->

- Logos Delivery:
  - Mix
    - Nodes ship in the LogosDev and LogosTest presets.
    - The exit node is drawn with the node's CSPRNG.
    - A mixed message is never confirmed against a store node.
  - Rate Limit Manager now drives the send path: admission follows RLN's remaining epoch budget ([#4309](https://github.com/logos-messaging/logos-delivery/pull/4309)), with a configurable approached state ([#4301](https://github.com/logos-messaging/logos-delivery/pull/4301)) and ephemeral messages dropped as it nears the limit ([#4303](https://github.com/logos-messaging/logos-delivery/pull/4303)).
  - QUIC is enabled by default, falling back to TCP when it stalls ([#4337](https://github.com/logos-messaging/logos-delivery/pull/4337)).
  - The messaging REST API is ready for DST: correct status codes ([#4329](https://github.com/logos-messaging/logos-delivery/pull/4329)), a configurable cache that reports overflow instead of hiding it ([#4330](https://github.com/logos-messaging/logos-delivery/pull/4330)), endpoint tests and docs ([#4331](https://github.com/logos-messaging/logos-delivery/pull/4331)).
  - The RLN bridge lost its worker threads and queues — every request rides Logos Core's own async machinery ([delivery-module#132](https://github.com/logos-co/logos-delivery-module/pull/132)).
