## Highlights
<!-- Please Add the team weekly highlights here -->

- Logos Delivery:
  - status.prod store nodes froze on Postgres after the v0.39.1 deploy ([#4526](https://github.com/logos-messaging/logos-delivery/issues/4526)); root-caused and fixed — database calls never block the event loop again ([#4531](https://github.com/logos-messaging/logos-delivery/pull/4531)) and hash queries no longer plan every partition ([#4532](https://github.com/logos-messaging/logos-delivery/pull/4532)). [v0.39.2](https://github.com/logos-messaging/logos-delivery/releases/tag/v0.39.2) shipped with the fixes.
  - the message-sending machinery was rewritten: concurrent sends, one task pipeline for mix, RLN, ephemeral and reliability ([#4517](https://github.com/logos-messaging/logos-delivery/pull/4517)).
  - store sync now follows the WAKU-SYNC wire formats, so an implementation written from the spec can sync with us ([#4571](https://github.com/logos-messaging/logos-delivery/pull/4571)).
  - codecs moved to proto3 and minprotobuf is retired ([#4488](https://github.com/logos-messaging/logos-delivery/pull/4488)); every store, lightpush and sync read is now size-bounded ([#4489](https://github.com/logos-messaging/logos-delivery/pull/4489)).
- Status:
  - status-go and Status App run v0.39.2 ([#7936](https://github.com/status-im/status-go/pull/7936), [#22798](https://github.com/status-im/status-app/pull/22798)); legacy store is off on prod ([infra-status#71](https://github.com/status-im/infra-status/pull/71)).
