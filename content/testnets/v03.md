## Logos Core

* Logos Storage-backed package manager

### Modules
* Chat
    - RLN support
* Delivery
* LEZ
* LEZ Indexer
* Blockchain
* Storage
* RLN Membership
    - generalized membership module; in v0.3 used by delivery module
    - contract deployed on LEZ
* Service Discovery
    - supports efficient, resilient capability discovery
    - in v0.3: used by Delivery module
    - future: used for Logos-wide service discovery
* Mix
  - Standalone module running the libp2p mix protocol suite with opinionated configuration for Logos Mix
* Wallet (Ethereum, Bitcoin, Monero, and Zcash)

### LEZ programs
* Token
* DEX
* Oracle

## Basecamp

* Improved UIs for all apps

### Apps
* Blockchain Dashboard
* LEZ Wallet
* LEZ Explorer
* Chat (supports mix)
* Storage Control and File Sharing
* DEX
* Wallet (Ethereum, Bitcoin, Monero, and Zcash)

## AnonComms

* Improved the Service Discovery module API to allow multiple modules to use one Service Discovery instance
* Basic λAccount library implemented and integrated into the Logos Chat module
* Improved de-MLS recovery mode implemented and integrated into the Logos Chat module
* Mix improvements—including advanced DoS protection, cover traffic generation, and improved Sphinx encryption—integrated into the Logos Delivery module and exposed through the Messaging API
  - Logos Chat provides the user-facing option to publish via mix

## Blockchain

### Base Layer
* EmPoWering
    - decentralized, permissionless onboarding; no faucet required
* Support for staking LEZ-bridged assets on the Base Layer

### LEZ
* Decentralized sequencing

## Messaging
### Delivery
* Production-ready Messaging API
* Feature-complete Reliable Channel API
* Uses RLN via the RLN module, with its contract deployed on LEZ
* Uses the Logos Service Discovery module

### Chat
* Feature-complete Chat API
* Supports RLN, Scalable Data Sync (SDS), mix, and de-MLS

## Storage

* Downloads over mix
  - Uses the large-message transport layer
  - Runs over Logos Mix using the AnonComms deployment with RLN
