# Design System: Testnet v0.4

**Track:** [Design System Track](/logoscore/roadmap/design-system.md)

**Estimated date of completion**: Testnet v0.4 launch

**Priority**: depends on effort; picked up once the other v0.4 milestones are done.

## Deliverables

### Theming support

- [ ] Custom themes: users add a theme file and Basecamp applies it to the existing design system, with no design system or UI changes

### Mobile readiness

- [ ] Token layer: controls read named tokens, not literals
- [ ] Mobile-aware tokens: density, touch targets, spacing
- [ ] Touch-ready controls and widgets: 44 px targets, no hover-only behaviour
- [ ] Theming sweep across apps: remove hard-coded colours and sizes
- [ ] Developer kit: reference app, module template, mobile-ready UI guide
