# Logos Core C3A Track

The Logos Core CDDL Contract Commitment Architecture (C3A) is the reworked Core, with CDDL-based module contracts.
It brings new features such as:

- Module lifecycle management
- Auth system for inter-module calls
- Cross-instance communication
- Commitment Model for verification of requests/responses/events
- Support for Mobile platforms

This is a breaking change: modules written for the current Core will not be loadable in the new one, and vice versa.
