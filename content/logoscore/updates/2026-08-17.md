# Logoscore Weekly Update — 2026-08-17

## Highlights

- **Basecamp runs on Windows.** First end-to-end x86_64-windows cross-build lands across the stack — Basecamp bundled with the real bundler, logosctl runs a module on Windows, and CI runs `lgx-cli` doctests on real Windows [logos-basecamp#323](https://github.com/logos-co/logos-basecamp/pull/323), [#324](https://github.com/logos-co/logos-basecamp/pull/324), [logos-logoscore-cli#84](https://github.com/logos-co/logos-logoscore-cli/pull/84), [logos-package#34](https://github.com/logos-co/logos-package/pull/34)

### logos-protocol reliability

Deep pass on the plain (Qt-free) transport and QtRO edge cases.

- **Correctness:** caller timeout now bounds the token handshake; event subscriptions survive an unreachable module; CALL held until module is reachable via `whenObjectAvailable`; async callbacks delivered in a Qt-free host; dropped install replies distinguished from failed installs upstream in PMUI [logos-protocol#47](https://github.com/logos-co/logos-protocol/pull/47), [#50](https://github.com/logos-co/logos-protocol/pull/50), [#53](https://github.com/logos-co/logos-protocol/pull/53), [#55](https://github.com/logos-co/logos-protocol/pull/55), [logos-package-manager-ui#67](https://github.com/logos-co/logos-package-manager-ui/pull/67)
- **Lifetime / races:** completion subscription lifetime bounded; second handle no longer steals the first's event channel; calls answered on registration-during-failure instead of waiting for deadline [logos-protocol#45](https://github.com/logos-co/logos-protocol/pull/45), [#49](https://github.com/logos-co/logos-protocol/pull/49), [#52](https://github.com/logos-co/logos-protocol/pull/52)
- **Perf:** per-call waiter thread folded into a call object with its own clock [logos-protocol#46](https://github.com/logos-co/logos-protocol/pull/46)
- **Tests:** burst-drain bounded against the burst, host destroyed on the emitting thread, registry probe no longer starves its waiter, arm-now probe pinned against QtRO-held replica [logos-protocol#51](https://github.com/logos-co/logos-protocol/pull/51), [#54](https://github.com/logos-co/logos-protocol/pull/54), [#56](https://github.com/logos-co/logos-protocol/pull/56), [#57](https://github.com/logos-co/logos-protocol/pull/57)
