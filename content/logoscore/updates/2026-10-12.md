# Logoscore Weekly Update — 2026-10-12

## Highlights

- **Upgraded modules actually load.** A newer installed version is no longer shadowed by an older bundled copy [logos-package-manager#48](https://github.com/logos-co/logos-package-manager/pull/48), [logos-logoscore-cli#178](https://github.com/logos-co/logos-logoscore-cli/pull/178)
- **New: Uplink app.** A Basecamp app for the node referral programme; the first PR adds tests [logos-uplink-app#1](https://github.com/logos-co/logos-uplink-app/pull/1)
- **One signing interface.** A shared `logos.signer/1` interface and a signer manager; the keystore, Keycard and Keycard Shell are now signers behind it [logos-signer-interface#1](https://github.com/logos-co/logos-signer-interface/pull/1), [logos-signer-manager-module#1](https://github.com/logos-co/logos-signer-manager-module/pull/1), [logos-keycard-module#1](https://github.com/logos-co/logos-keycard-module/pull/1), [logos-keycard-shell-module#1](https://github.com/logos-co/logos-keycard-shell-module/pull/1)
- **Basecamp for app developers.** `--module` runs only the app under development, and the shell's own QML now hot-reloads [logos-basecamp#489](https://github.com/logos-co/logos-basecamp/pull/489), [logos-basecamp#492](https://github.com/logos-co/logos-basecamp/pull/492)
- **Zcash wallet: local Zebra node, Tor per server, ZIP 318 migration, and Windows builds** [logos-zcash-wallet-ui#1](https://github.com/logos-co/logos-zcash-wallet-ui/pull/1), [logos-zcash-wallet-ui#2](https://github.com/logos-co/logos-zcash-wallet-ui/pull/2), [logos-zcash-wallet-ui#7](https://github.com/logos-co/logos-zcash-wallet-ui/pull/7), [logos-zcash-wallet-core-module#2](https://github.com/logos-co/logos-zcash-wallet-core-module/pull/2), [logos-zcash-wallet-core-module#11](https://github.com/logos-co/logos-zcash-wallet-core-module/pull/11)
- **Blockchain UI 0.3.1 claim fixes shipped**, and the module gained a mock node for testing without a real one [logos-modules-release#101](https://github.com/logos-co/logos-modules-release/pull/101), [logos-modules-release#102](https://github.com/logos-co/logos-modules-release/pull/102), [logos-blockchain-module#110](https://github.com/logos-blockchain/logos-blockchain-module/pull/110)
