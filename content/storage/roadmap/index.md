## Roadmap Overview

The Logos Storage team is currently working on:

1. [[frontends-filesharing-rme | Create A Basic File Sharing Client for Logos Core]], by rolling out a minimal implementation which allows storing, sharing, and organically replicating frontends, modules, and files.
2. [[privacy-preserving-filesharing-rme | Privacy-Preserving File Sharing]], where we enhance our filesharing implementation to provide privacy-preserving capabilities such as publisher and downloader unlinkability, and plausible deniability for cache nodes.

Both are key to the Logos effort - without storage, neither applications/frontends nor modules can be distributed effectively.
