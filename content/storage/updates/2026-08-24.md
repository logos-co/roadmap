## Week 34 2026 (Mon Aug 17 - Fri Aug 21, 2026)

### Highlights

* Progress continues on [hidden services over mix](https://hackmd.io/@codex-storage/HyU6451wGl): the anonymous download path selection part of the draft spec is now complete, informed by a study of Tor's [Vanguard proposal](https://spec.torproject.org/proposals/292-mesh-vanguards.html) and its [path-selection simulation work](https://github.com/asn-d6/vanguard_simulator).
* Package Manager work moved forward on the release pipeline: Storage was added to the release process ([#17](https://github.com/logos-co/logos-modules-release-action/pull/17)), the index rebuild process now includes `urls` ([#6](https://github.com/logos-co/logos-modules-release-tool/pull/6)), and a Storage node was deployed on Digital Ocean to test the release flow end to end.
* Storage UI shipped a fix for a Windows issue ([#87](https://github.com/logos-co/logos-storage-ui/pull/87)) and an updated Module builder dependency ([#89](https://github.com/logos-co/logos-storage-ui/pull/89)).

### [Hidden Services Over Mix](https://github.com/logos-storage/logos-storage-pm/issues/20)

- **achieved:**
    - completed the anonymous download path selection part for [the draft spec](https://hackmd.io/@codex-storage/HyU6451wGl). 
    - studied Tor’s [Vanguard proposal](https://spec.torproject.org/proposals/292-mesh-vanguards.html ), their [formulas and stats](https://spec.torproject.org/vanguards-spec/vanguards-stats.html ), and their [simulation work](https://github.com/asn-d6/vanguard_simulator ). Aim is to understand their reasoning behind their hidden service path selection parameters.
- **next:**
    - build on Tor’s simulation work to evaluate the time-based path selection for hidden services. 
    - add the resulting time-based path selection strategy to the draft spec.
