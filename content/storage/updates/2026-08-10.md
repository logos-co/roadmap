## Week 32 2026 (Mon Aug 3 - Fri Aug 7, 2026)

### Highlights

* [**v2.1.0 of the Logos storage module is out**](https://github.com/logos-co/logos-storage-module/releases/tag/v2.1.0). It brings [libstorage v0.4.2](https://github.com/logos-storage/logos-storage-nim/releases/tag/v0.4.2) with major improvements to NAT traversal as well as other bugfixes and improvements. The [UI module](https://github.com/logos-co/logos-storage-ui/releases/tag/v2.1.0) was also updated and now has a much simpler onboarding process, a new network connectivity indicator, and an overall more polished UI.
* The Large Data Transport Layer for Mix now has a [draft design spec](https://hackmd.io/3qYnQwe_S9OrHAmIS5rY4A) available on HackMD; a preliminary implementation will soon follow.

### [Hidden Services Over Mix](https://github.com/logos-storage/logos-storage-pm/issues/20)

- **achieved:**
    - Worked on the mix path selection simulation and [research document](https://hackmd.io/@codex-storage/rJ4d1aaHfe) for anonymous download. To be posted on the forum.
    - Review the [DoS schemes](https://app.notion.com/p/DoS-schemes-for-Mix-step-by-step-Mix-protocol-unmodified-3ac8f96fb65c80929d04eced80709f19) and research solutions to improve efficiency.
- **next:**
    - drafting a spec for anonymous download session-based path selection based on the experiment/computation results.
    - Experiment and followup document on hidden services time-based path selection and write spec for it.

### [Large Data Transport Layer for Mix](https://github.com/logos-storage/logos-storage-pm/issues/2)

- **achieved:**
    - review of [nim-libp2p-mix/pull/36](https://github.com/logos-co/nim-libp2p-mix/pull/36)
    - Draft Design Spec for the Mix Transport: https://hackmd.io/3qYnQwe_S9OrHAmIS5rY4A
    - Exposing low level functional API from Mix Protocol in order to support higher level Mix Transport (plugging architecture). Without external MixTransport plugin, default Mix Protocol embedded transport will be used
        - https://github.com/logos-co/nim-libp2p-mix/tree/feat/mix-transport
    - Draft WIP PR in the Mix Transport repo, where the actual Mix Transport is being developped:
        - https://github.com/logos-storage/libp2p-mix-transport/pull/1
- **next:**
    - continuing working on the MixTransport implementation - first end-to-end draft implementation should be ready by the end of the week
