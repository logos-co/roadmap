## Week 38 2026 (Mon Sep 14 - Fri Sep 18, 2026)

### Highlights

* Implementation for anonymous downloads over Mix is complete, and initial testing shows that it works.
* Package Manager has been integrated into Basecamp.
* Both the Storage Module and Storage UI now supports - and have been shown to run correctly - under Windows.

### [Large Data Transport Layer for Mix](https://github.com/logos-storage/logos-storage-pm/issues/2)

- **achieved:**
    - Mix Transport
        - reviewing and refactoring the integration with the block exchange protocol
        - aligning Mix Transport integration with what we currently have on master block exchange protocol
            - introducing policies for a number of variation points (e.g. swarm selection, swarm admission, querying for presence)
            - Mix Transport runs on the same default policies as direct downloads
        - setting up local harness and getting it to run tests locally
            - experimenting with concurrent SURB redundancy transmission - observed over 20% increased throughput (in average: for transmitting 1MiB from e.g. from 61.961s to 47.902s)
- **next:**
    - final review and preparing for merging
    - review generated docs, in particular getting a draft of the Mix Transport spec.
