### [Large Data Transport Layer for Mix](https://github.com/logos-storage/logos-storage-pm/issues/2)

- **achieved:**
  - preparing [MixTransport PR](https://github.com/logos-storage/libp2p-mix-transport/pull/1), [low-level Mix API PR](https://github.com/logos-co/nim-libp2p-mix/pull/47)
  - new [PR #5](https://github.com/logos-storage/libp2p-mix-transport/pull/5) - allow the recipient (one of the roles in the MixTransport session) to send the two redundant copies of each reverse Data frame concurrently, enabled by compiling with `-d:mixExperimentConcurrentDataCopies`. We will most probably make it the default and remove the compile flag - to be confirmed with the team.
