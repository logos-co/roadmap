## Week 37 2026 (Mon Sep 7 - Fri Sep 11, 2026)

### Highlights

* Our [hidden services simulator](https://github.com/logos-storage/hs-mix-sim/) is complete, with reference path selectors and scripts to reproduce the research results. We ran [experiments across different configurations and threat models](https://github.com/logos-storage/hs-mix-sim/blob/main/results.md).
* We are documenting a set of [RLN optimizations](https://github.com/logos-storage/nim-groth16/tree/dynamic) that should reduce single-core proving time from 200 ms to 15 ms, with a preprint planned.

### [Large Data Transport Layer for Mix](https://github.com/logos-storage/logos-storage-pm/issues/2)

- **achieved:**
    - Mix Transport
        - testing, debugging and analysis under multiple netem profiles
        - merged testing harness branch and aligned on the changes introduced there (e.g. `connect` concurrency handling)
        - integration with block exchange protocol
            - first draft implementation pushed
        - initial work on adapting the existing Logos storage testing harness for Mix transport tests
- **next:**
    - Mix Transport
        - reviewing and refactoring the integration with the block exchange protocol
        - hardening and fixing problems we discover through testing
        
### [Hidden Services Over Mix](https://github.com/logos-storage/logos-storage-pm/issues/20)

- **achieved:**
    - finished work on the [hidden services simulator](https://github.com/logos-storage/hs-mix-sim/), and made scripts to easily validate results. 
    - reference implementation for the path selectors and used them to run [multiple experiments](https://github.com/logos-storage/hs-mix-sim/blob/main/results.md) with different configuration and threat models.
- **next:**
    - second iteration on the [path selection spec](https://github.com/logos-co/logos-lips/pull/445) and requested reviews. 
    - continue work on the [hidden service spec](https://github.com/logos-co/logos-lips/pull/330) with the specified path selection strategy.

### RLN optimizations

- **achieved:**
    - measurable progress on documenting the [more hardcore RLN optimizations](https://github.com/logos-storage/nim-groth16/tree/dynamic) (200ms -> 15ms proving time, single core)
    - coordinating with the Zerokit team about the [Poseidon2 hash function](https://github.com/vacp2p/circom-rln/pull/1) conventions
- **next:**
    - finish documenting the RLN optims (this should result in a preprint, as that seems to be most applicable format)

### [Package Manager](https://github.com/logos-storage/logos-storage-pm/issues/25)

- **achieved:**
    - Moved the configuration migration feature to the Storage Module ([PR](https://github.com/logos-co/logos-storage-module/pull/86)) in order to provide a way for consumers (UI, logosctl, basecamp) to refresh the configuration after an update.
    - Applied this move on Storage UI ([PR](https://github.com/logos-co/logos-storage-ui/pull/92)).
    - Added a configuration option to not advertise content ([PR](https://github.com/logos-storage/logos-storage-nim/pull/1523)). 
    - Started the work of adding Storage Module as optional dependency into Package Downloader Module after the logos module builder shipped the feature. 
- **next:**
    - Complete the optional dependency integration work for Package Downloader Module and Basecamp 
    - Bring all the differents PRs together and work on Storage UI to filter the LGX packages
