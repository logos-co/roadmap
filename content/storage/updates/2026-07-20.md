## Week 29 2026 (Mon Jul 13 - Fri Jul 17, 2026)

### Highlights

- In a joint decision with the Logos documentation team we are now revamping our documentation to use Docusaurus.
- Logos Storage now uses [nim-protobuf-serialization](https://github.com/status-im/nim-protobuf-serialization) instead of manually written protobuf serializers.
- [Logos Storage UI](https://github.com/logos-co/logos-storage-ui) is now mostly aligned with the Logos Design System.

### [Hidden Services Over Mix](https://github.com/logos-storage/logos-storage-pm/issues/20)

- **achieved:**
    - completed the implementation of the free-route mix [(`freeroutesim`)](https://github.com/logos-storage/hs-mix-sim/tree/main/crates/freeroutesim) simulator for simulating the path selection and malicious-path problem. This helps us study the problem better in the mix protocol that we are using. 
    - improved documentation of the simulator and results.
- **next:**
    - Continue research and study the problem in the context of anonymous download using the transport layer since the problem still exists there.

### Misc
- **achieved:**
    - Migrated all wire protocols from minprotobuf to nim-protobuf-serialization
