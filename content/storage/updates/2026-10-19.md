## Week 42 2026 (Mon Oct 12 - Sun Oct 18, 2026)

### Highlights

- libstorage now uses [nim-ffi-generated C bindings](https://github.com/logos-storage/logos-storage-nim/pull/1519), retiring lots of hand crafted code and aligning our codebase with how the rest of the Nim libraries in the Logos ecosystem should work.
- Storage UI now allows downloads to be cancelled, and displays package download source (e.g. Logos Storage, Github, Local).

### [Block Protocol and Mix Transport Optimizations](https://github.com/logos-storage/logos-storage-pm/issues/33)

- **achieved:**
  - Validated the [swarm fix](https://github.com/logos-storage/logos-storage-nim/pull/1540) against a real Basecamp file-sharing application: the test delivered files in five out of five runs with the branch, compared with zero out of five on stock v0.5.3. [Test report](https://github.com/logos-storage/logos-storage-nim/pull/1540#issuecomment-6187343523).
  - Tested bandwidth-delay-product-based congestion control and pipeline-depth adjustments for downloads over Mix.
- **next:**
  - Merge the swarm changes before integrating the congestion-control adjustments.

### [Large Data Transport Layer for Mix](https://github.com/logos-storage/logos-storage-pm/issues/2)

- **achieved:**
  - evaluated delay aggregation across redundant SURBs in the [Mix transport implementation](https://github.com/logos-storage/libp2p-mix-transport/pull/1), with reported performance improvements.
  - preparing offsite materials, 3 presentations:
    - How Mix Transport works: https://link.excalidraw.com/p/readonly/wwjdpF3ENvcSHWYzBGDF
    - MixTransport to Mix Protocol Boundary Flow: https://link.excalidraw.com/p/readonly/8JjIsQONRWfqEUCImebj
    - Mix Protocol API changes: https://link.excalidraw.com/p/readonly/VEtXqX24uy9YAFQLWV8B
    - editable version with additional documentation in the Logos Storage Obsidian vault
- **next:**
  - offsite Georgia

### [Logos Core Integration](https://github.com/logos-storage/logos-storage-pm/issues/40)

- **achieved:**
  - Merged [nim-ffi-generated C bindings](https://github.com/logos-storage/logos-storage-nim/pull/1519), replacing the hand-written libstorage runtime.
  - Merged a [private-download session fix](https://github.com/logos-storage/logos-storage-nim/pull/1554) for a regression introduced by the migration.
  - Continued adapting the [Storage Module to the generated bindings](https://github.com/logos-co/logos-storage-module/pull/83).
  - Implemented a [download cancel button in Storage UI](https://github.com/logos-co/logos-storage-ui/pull/102), with doctests.
  - Updated and released [Go bindings](https://github.com/logos-storage/logos-storage-go-bindings/pull/30) and [Rust bindings](https://github.com/logos-storage/storage-rust-bindings/pull/9) for Storage v0.5.3. Go builds now use [release artifacts](https://github.com/logos-storage/logos-storage-go-bindings/pull/31), and the [Go example](https://github.com/logos-storage/logos-storage-go-bindings-example/pull/7) was updated. These releases precede the nim-ffi ABI migration.
  - Implemented network-aware package-source availability across the [downloader](https://github.com/logos-co/logos-package-downloader/pull/53), [module](https://github.com/logos-co/logos-package-downloader-module/pull/59), and [UI](https://github.com/logos-co/logos-package-manager-ui/pull/96): show the Storage source icon only when the local Storage node is running on the package's network.
  - Prepared [Basecamp integration](https://github.com/logos-co/logos-basecamp/pull/509), including checks for matching networks, nonmatching networks, and stopped nodes.
- **next:**
  - Finish the Storage Module integration and address download/error-handling issues.

### [Hidden Services Over Mix](https://github.com/logos-storage/logos-storage-pm/issues/20)

- **achieved:**
  - Revised the [hidden-service specification](https://github.com/logos-co/logos-lips/pull/330) with path selection and math-rendering metadata.

### [Deal with ephemeral nodes](https://github.com/logos-storage/logos-storage-pm/issues/39)

- **achieved:**
  - Documented the stale-provider-record problem surfaced by [download diagnostics](https://github.com/logos-storage/logos-storage-nim/issues/1556), and outlined graceful departure, shorter advertisement cycles, and delayed advertising as possible mitigations. No mitigation was implemented this week.
- **next:**
  - Evaluate the proposed mitigations, including the tradeoffs of graceful departure and shorter advertisement cycles.

### Misc

- Updated the pending [nim-libp2p v2.4.0 integration](https://github.com/logos-storage/logos-storage-nim/pull/1546), including nonblocking AutoNAT dials and removal of obsolete NAT parameters.
- Opened an upstream [AutoNATv2 peer-selection fix](https://github.com/iftech/nim-libp2p/pull/3279) to select peers supporting the server protocol.
- Switched nim-groth16 random field-element generation, including proof-masking coefficients, to [Constantine's cryptographically secure RNG](https://github.com/logos-storage/nim-groth16/commit/8161581829457be459e22029cd71e26e78a8c8e6).
- Merged [value separators for multivalued environment variables](https://github.com/logos-storage/logos-storage-nim/pull/1553).
- Merged the [v0.4 roadmap update](https://github.com/logos-co/roadmap/pull/575), including the naming-service direction.
