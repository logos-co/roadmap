Key Highlights

Messaging

Logos Delivery’s message-sending machinery was rewritten — concurrent sends, with one task pipeline for mix, RLN, ephemeral and reliability (#4517); codecs also moved to proto3 and minprotobuf is retired (#4488).

Logos Core

Basecamp is now the dev host — UI modules run and test inside Basecamp’s standalone mode, which replaces logos-standalone-app (the builder’s lock drops from 404 to 96 nodes); Package manager UI, Blockchain UI, LEZ wallet and the tutorials have moved over.

Logos Core

QR signing and multi-signer accounts — a new signer for BC-UR wallets plus a QR scanner module where only a sandboxed helper opens the camera and returns only the decoded text; the signer manager now lists each account once with every signer that holds it.

Storage

libstorage now uses nim-ffi-generated C bindings, retiring the hand-written runtime; Storage UI can now cancel downloads and shows each package’s download source.

Blockchain

Node 0.3.2 released: OpenMetrics exposed, gossip stability fixes 0.3.2

Blockchain

Logos Execution Zone transactional actors merged: atomic composition and asynchronous messaging across public and private execution #935; wallet storage now encrypted with the wallet password #987
