Key Highlights

Blockchain

Testnet 0.3.0 released — node 0.3.0 and Logos Execution Zone v0.3.0, while hard fork support (fork digest, era deployment settings, protocol names derived from the fork digest) landed in the node (#3679, #3683, #3687, #3689).

Messaging

Logos Delivery v0.39.0 released and two milestones closed — Messaging API — General Availability and RLN on Logos Blockchain. status-go and Status App both run v0.39.0 (#7860, #22606).

Logos Core

The 0.3.0 catalog was cut in about 48 hours — shipping the LEZ 0.3.0 stack, libp2p 1.1.0, storage 3.0.2 and blockchain-ui 0.3.1; ten pins rolled back by a stale-checkout bump were restored within six hours (#78, #85).

Logos Core

Installs offer optional dependencies, and packages can come over Logos Storage — the same way in Basecamp, PMUI and logosctl, where a failed optional no longer stops the install; a new setting allows any transport, Storage only, or HTTP only (downloader #44, #42, basecamp #416).

AnonComms

Logos Delivery runs with LEZ-based RLN on the hosted testnet, using the RLN membership management module; the Logos Oracle Network performance report benchmarking the Oracle Zone is published.

Storage

Logos testnet v0.3 launched with new storage module and storage UI v3.0.2 releases; a research call on Mix path selection strategies is set for 2026-10-07 (slides).
