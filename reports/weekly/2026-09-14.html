Note: Messaging, AnonComms, Logos Core, and Storage have reported. The Blockchain section will be added as its updates land.

Key Highlights

Messaging

Delivery now runs RLN live via the membership module — logos-delivery exposes an RLN plugin interface, logos-delivery-module implements it against logos-rln-module, and RLN runs in the delivery demo (#448 closed).

Messaging

Offline-period backfill landed — history on your subscribed content topic is now queried automatically from Store nodes for any period the node was offline (#430 closed).

Messaging

LIP-243 segmentation integrated into the Reliable Channel API (#318 closed), and the v0.39.0-rc.2 release process kicked off.

AnonComms

Poseidon2 benchmark published — comparing Zerokit's implementation against other Rust implementations, both natively and on risc0.

AnonComms

Standalone service discovery is now integrated into Logos Delivery on both the liblogosdelivery and logos-delivery-module sides, tested locally in a docker-compose harness and awaiting approval.

Logos Core

Optional dependencies landed, from the LIDL grammar to the app — a third dependency kind (concrete modules a module may call but does not require), held apart at every layer: the loader never auto-loads them, never reports one as missing, and never fails a load over one.

Logos Core

Basecamp is a real Windows application — a GUI-subsystem exe with child hosts spawned CREATE_NO_WINDOW (10 console windows → 2) and an NSIS installer with a portable mode (113 MB → 51 MB).

Logos Core

The completion channel is now reserved for transports — __logos_call_complete__, which carries a deferred call's return value, is off every module's event surface at onEvent() and in wildcard fan-out.

Storage

The hidden services simulator is complete — reference path selectors and scripts reproduce the research, with experiments across configurations and threat models.

Storage

Documenting a set of RLN optimizations that should cut single-core proving time from 200 ms to 15 ms, with a preprint planned.
