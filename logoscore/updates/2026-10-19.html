Logoscore Weekly Update — 2026-10-19

Highlights

This week, technically

AreaWhat changedStatusPRs
Multi-signer accountsThe signer manager lists each account once, with every signer that holds it, and the user picks one per request. Adopted by the Ethereum, Bitcoin and Uniswap wallets and the keys appmergedlogos-signer-manager-module#11, logos-signer-interface#6, logos-account-kit#1, logos-eth-wallet-ui#38, logos-bitcoin-wallet-ui#11, logos-uniswap-ui#16, logos-evm-keystore-ui#20
QR signingNew signer for BC-UR wallets and a QR scanner module. Only a sandboxed helper opens the camera, and it returns only the decoded text. The signer manager consults it by default. macOS bundling now keeps a signed helper app’s camera entitlementmergedlogos-qr-signer-module#1, logos-qr-scanner-module#1, logos-qr-signer-ui#1, logos-signer-manager-module#9, nix-bundle-dir#25
KeycardOne app for card readers and the USB Shell, with card administration. The Keycard signers became optional dependencies of the signer manager, and the .lgx spec, liblogos and the docs now cover optional dependenciesmergedlogos-keycard-ui#3, logos-keycard-module#3, logos-keycard-shell-module#3, logos-signer-manager-module#10, logos-package#48, logos-liblogos#242
Bitcoin walletSyncs from a remote Bitcoin Core node. Headers are stored once per network and shared by its wallets, so a new or reset wallet no longer downloads the whole header chain again. Header download progress is shown, sends below the dust limit are refused, and fees fall back to the server’s mempool when no estimate is availablemergedlogos-bitcoin-wallet-core-module#1, #7, #11, #13, logos-bitcoin-node-module#1
EVM send pathTimeouts are now sized from the chain’s RPC timeout. When a route can’t take a state override, the fee module falls back to a gas-limit hint. Verified proxy 0.1.4 fixes Uniswap quotes failing with “Unable to get slot”merged; proxy 0.1.4 in the cataloglogos-evm-tx-sender-module#12, logos-evm-fee-module#11, logos-evm-eth-rpc-module#20, logos-modules-release#116
Basecamp as the dev hostUI modules now run and test inside Basecamp’s standalone mode, which replaces logos-standalone-app (the builder’s lock drops from 404 to 96 nodes). Standalone mode can also load other apps. Package manager UI, Blockchain UI, LEZ wallet and the tutorials have moved overmergedlogos-module-builder#274, logos-basecamp#506, logos-basecamp#507, logos-package-manager-ui#95, logos-blockchain-ui#97, logos-tutorial#117
BasecampA basecamp:// link to an app that isn’t installed now offers to install it. Also fixed a race in the intent breaker testsmergedlogos-basecamp#503, #505
CI speed20 repos now read from and publish to the Logos nix cache. On the storage module this cut the test job from 17.4 to 6.3 minmergede.g. logos-liblogos#240, logos-design-system#64; see appendix
Node metricsThe release test set now turns on the Blockchain module’s OpenMetrics and scrapes themmergedlogos-release-set#13, #14
Uplink appSigning flows; UI tests run with nix run .#ui-testsmergedlogos-uplink-app#2, #3
