Logoscore Weekly Update — 2026-10-12

Highlights

  • Upgraded modules actually load. A newer installed version is no longer shadowed by an older bundled copy logos-package-manager#48, logos-logoscore-cli#178
  • New: Uplink app. A Basecamp app for the node referral programme; the first PR adds tests logos-uplink-app#1
  • One signing interface. A shared logos.signer/1 interface and a signer manager; the keystore, Keycard and Keycard Shell are now signers behind it logos-signer-interface#1, logos-signer-manager-module#1, logos-keycard-module#1, logos-keycard-shell-module#1
  • Basecamp for app developers. --module runs only the app under development, and the shell’s own QML now hot-reloads logos-basecamp#489, logos-basecamp#492
  • Zcash wallet: local Zebra node, Tor per server, ZIP 318 migration, and Windows builds logos-zcash-wallet-ui#1, logos-zcash-wallet-ui#2, logos-zcash-wallet-ui#7, logos-zcash-wallet-core-module#2, logos-zcash-wallet-core-module#11
  • Blockchain UI 0.3.1 claim fixes shipped, and the module gained a mock node for testing without a real one logos-modules-release#101, logos-modules-release#102, logos-blockchain-module#110

Initiatives

Packages and catalog

  • Newest version wins across module dirs, and logosctl searches the session dir last logos-package-manager#48, logos-logoscore-cli#178, #179, logos-basecamp#479
  • A catalog refresh now updates App Manager, PMUI and an open Add Application dialog logos-package-downloader#49, logos-package-downloader-module#56, logos-basecamp#490, #491, logos-package-manager-ui#94

Uplink app (new)

  • New repo logos-uplink-app: invite other node operators, earn points while they run Blend core nodes, collect on LEZ and cash out. LEZ referral calls are still stubbed logos-uplink-app#1

Signers and keys

  • logos.signer/1 with a mock signer and conformance suite; signer_manager_module runs approvals over it, and the Signer app, signer CLI, tx sender and wallet doctests now approve through it logos-signer-interface#1, logos-signer-interface#3, logos-signer-manager-module#1, logos-signer-manager-module#3, logos-evm-keystore-module#27, logos-evm-signer-ui#22, logos-evm-signer-cli#12, logos-evm-tx-sender-module#10, logos-eth-wallet-backend#30
  • New Keycard and Keycard Shell modules and apps logos-keycard-module#1, logos-keycard-ui#1, logos-keycard-shell-module#1, logos-keycard-shell-ui#1
  • The keys app and CLI gain Bitcoin wallets, kept recovery phrases and device accounts logos-evm-keystore-ui#13, logos-evm-keystore-ui#16, logos-evm-keystore-cli#8, logos-evm-keystore-module#28

Zcash wallet

  • Reads from a local Zebra node over Logos IPC, cross-checked against a server; Tor chosen per server; ZIP 318 migration with “Move now”; regtest harness and Windows builds across the stack logos-zcash-wallet-core-module#2, logos-zcash-wallet-core-module#7, logos-zcash-wallet-core-module#11, logos-zcash-wallet-core-module#5, logos-zcash-wallet-core-module#1, logos-zcash-wallet-ui#1, logos-zcash-wallet-ui#4, logos-zcash-wallet-ui#7, logos-zebra-nix#1, logos-zebrad-module#2

Monero 0.1.1

  • The Monero stack moved to Monero v0.18.5.3, released 0.1.1 with version ranges on dependencies; the catalog is bumped to match logos-monero-nix#2, logos-monero-wallet-ui#9, logos-monerod-ui#3, logos-modules-release#108

Basecamp developer experience

  • Standalone mode (--module) and mkPluginTest for headless app tests; hot reload of Basecamp’s own QML via nix run .#ui-dev logos-basecamp#489, #492, #477

Releases

  • Storage UI 3.0.2, LEZ 0.3.1 and the wallet UI calibration fix; the Basecamp installer is now smoke-tested on Windows logos-modules-release#103, #105, logos-execution-zone-module#66, logos-release-set#12

Blockchain UI

  • Mock backends in logos-blockchain-module let the module be tested without a running node logos-blockchain-module#110
  • Rewards: “Awaiting payout” card, in-flight claims on the Earned tile, “Claiming…” state, and plain-language claim errors logos-modules-release#101, #102
