Logoscore Weekly Update — 2026-10-26

Highlights

  • Add Ethereum testnets to your wallet from Basecamp. The Ethereum RPC app now lets you show mainnets, testnets or both, and switch each chain on or off. You can add Sepolia to the wallet without leaving the app. (released in the app catalog as eth_rpc_ui 0.1.1) logos-eth-rpc-ui#8, logos-modules-release#122

Signed releasesThe catalog’s Jenkins pipeline (Linux and macOS) merges each module into an .lgx, signs it with a new Logos release key and uploads it to Logos Storage. The key’s DID is listed under trustedSigners. logoscore-cli got release pipelines for Linux x86_64/aarch64 and Windows. logos-json-rpc-bridge, which was never released, is out of the catalogmerged; the old signing key must be revoked before the pipeline is usedlogos-modules-release#48, #120, logos-logoscore-cli#77
Download sourceEach download reports its transport (Logos Storage or HTTP), and the package manager shows it. Under HTTP the storage node is never started. The downloader module reports the node’s state (off, waiting, starting, running, failed), and the source can be chosen before the node comes upmergedlogos-package-downloader#54, logos-package-downloader-module#60, logos-package-manager-ui#97, logos-design-system#69
BasecampThe welcome page is anchored to the top, so it no longer jumps while you search. The Logos λ replaces the tent mark in the sidebar and app icon. Nine new MCP UI tests cover repositories, inspectors and window hide/minimizemerged, not yet in a Basecamp releaselogos-basecamp#510, #511–#521
UplinkNew uplink_module runs the node referral program over lez_core (terms, enrolment, claims, cash-out), and the app now uses it instead of stubs. Joining and cash-out are signed with the node’s Blend key after the user confirms; the key stays outside the module. The app adds auto-claim, join progress, a devnet node and cash-out recovery. The Blockchain module’s read_accounts("") now reads the running node’s config, so another module can find the node’s keysmerged; no public deployment of the program yetuplink-module#1, #4, logos-uplink-app#4, #5, #10, #14, logos-blockchain-module#121
Zcash NU7Moved to librustzcash’s final NU7 releases (mainnet NU7 at height 3,543,405, about 2026-11-06), Zebra 7.0.0 with its security fixes, and lightwalletd v0.5.5. Without this, the wallet would refuse every mainnet server once NU7 activatesmergedlogos-zcash-node-module#6, logos-zcash-wallet-core-module#16, logos-zebra-nix#5, logos-zebrad-module#4
Bitcoin walletFixed a Kyoto wallet that stopped getting updates after a reorg while its status still showed it as synced. BDK patch releasesmergedlogos-bitcoin-wallet-core-module#15, #16
logosctllogoscore is no longer released, so the doc-tests and integration suites of 13 repos now drive logosctl. logoscore-py gets a logosctl Docker smoke image, and both Docker daemons accept env=mergede.g. logos-liblogos#243, logos-test-modules#80, logos-logoscore-py#34, #35; see appendix
UI fixesTabs, list items, checkboxes and text fields render in Public Sans instead of the system font. A signer’s refusal stays on screen. The Uniswap wallet picker no longer shows the address twice. The UI tutorials no longer mention logos-standalone-appmergedlogos-design-system#66, logos-evm-signer-ui#30, logos-uniswap-ui#17, logos-tutorial#118
