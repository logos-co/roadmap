2026-04-20 Logoscore Weekly

2026-04-20 Logoscore Weekly

Apr 20, 20263 min read

  • logoscore-updates

Overall

  • Major effort to remove Qt dependencies from the core stack (liblogos, cpp-sdk, module), replacing Qt types, process management, and improved logging with pure C++ alternatives to improve portability.
  • Added QML inspector support via MCP server for testing UI modules, integrated across module-builder, standalone-app, dev-boost, and tutorials.
  • Significant package management improvements: uninstall, dependency/dependent resolution, gated operations, and improved UI workflows.
  • Continued migration of UI apps (accounts, wallet, webview, counter) to the new QML + C++ backend architecture using module-builder.
  • View module runtime enhancements: event subscriptions from QML-only apps, long module name handling, and type preservation fixes.
  • AppImage performance improvements by disabling squashfs compression for faster startup.
  • Continuing refactor of cpp-sdk/liblogos to remove qt, implement CDDL, etc..
