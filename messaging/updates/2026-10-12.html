Logos Delivery

Messaging API — General Availability

  • [Deliverable] Offline periods backfill

    • achieved:
      • feat(messaging): topic records for the backfill (#4468).
      • feat(messaging): backfill engine for outages of live delivery — one in-memory state machine per subscribed topic, replacing the reconnection check and the startup catch-up (#4469), with its receive tests (#4470).
      • feat(messaging): backfill the downtime of a restart from the records (#4471), with its receive tests (#4472).
      • fix(messaging): topic-aware backfill engine, landing the five PRs above (#4474).

  • [Deliverable] Integrate Mix into Messaging API

    • achieved:

      • fix(chat2mix): replace the nested waitFor and runForever with await (#4410).
    • next:
      • Mix replies can fail for senders behind NAT (#4357).

Status

Status: Logos Delivery Integration

  • [Deliverable] Status: prepare the network for the Messaging API

    • achieved:
      • feat: configurable shard ids for auto-sharding, so a Messaging API node runs on Status’s shard 32 (#3963).
      • feat: extra listen-only shards, to keep receiving on shard 64 during Status’s shard migration (#4501).

  • [Deliverable] Status: build and link Logos Delivery in status-go and status-app

    • achieved:
      • nim-sds and sds-go-bindings moved to nim-ffi v0.3 (nim-sds#105, sds-go-bindings#26), taken up by logos-delivery (#4407).
      • logos-delivery resolves as a Nimble dependency: (#4424, #4429, #4534).
      • logos-delivery-go-bindings moved to the nim-ffi CBOR ABI (#135) and find the installed package by its nimble file (#133).
      • Android and iOS libraries built through Nimble by dependents (#4504, go-bindings#143).
      • Both Go bindings hold the native context as an integer, not a pointer (go-bindings#139, sds-go-bindings#28).
    • next:
      • Get the status-go and status-app CI green on the Nimble build.
    • blockers:
      • Status CI hosts run Nimble 0.22.2 or older; the build needs 0.26.0.

  • [Deliverable] Messaging API: close the gaps Status needs

    • achieved:
      • Go bindings expose the kernel API on the MessagingClient’s own node (#140) and report queued sends and the source of received messages (#141).
      • fix(kernel): register WakuMessage under its own proto path, so the bindings load next to go-waku (#144).
      • fix: destroying a node no longer leaks its message store and event descriptors (#4499).
      • fix(ffi): an over-cap request returns an error instead of crashing refc hosts (nim-ffi#226).
