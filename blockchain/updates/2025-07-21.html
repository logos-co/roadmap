Nomos Weekly Update - 2025-07-21 §

Nomos Bedrock §

Research §

  • Cryptoeconomics:
    • Cryptoeconomic thoughts plan documented for adopting TKE’s proposed PKI for block rewards
    • Work initiated on defining PKI parameters for each service and for leaders
    • Target justification and reward distribution strategies under development
  • Genesis Block:
    • Bedrock Genesis Block specification finalized and marked green
  • Cryptarchia v2 Analysis:
    • On the Closest Common Ancestor (CCA) Rule in v2/v2-prime draft analysis completed
    • Privacy-Preserving Best-Possible Unpredictable Proof-of-Stake (Part II) exploring alternative PPoS mechanisms
  • Total Stake Inference:
    • Total Stake Inference v2 Notes equation derivation showing ~15% underestimation in total stake
    • Preliminary Research: Total Stake Inference Analysis consolidating simulation validation results
    • Stability and convergence speed analysis completed with optimal learning rate derivation
  • Service Declaration Protocol:
    • Service Declaration Protocol Specification updated with session length parameters

Development §

  • Cryptarchia Core:
    • Initial fork choice rule selection refactoring in progress
    • IBD (initial block download) implementation under review
    • Initial Block Download integration testing completed
    • Chain service refactoring: #1431 & #1438 for improved code organization
  • Networking Enhancements:
    • Orphan blocks random peers in parallel implementation for improved efficiency
    • Sync network protocol timeouts handling added
  • Ledger and Transaction Processing:
    • Support for processing LedgerTxs implementation
    • Update gas calculations to follow new mantle specifications merged
    • Mempool item processing integration into node completed
    • SDP refactoring moving state machine and definitions to nomos-core
  • Cryptographic Utilities:
    • RNG updates across codebase for standardization
  • ZK Components:
    • Witness Generator Compilation for Linux, Windows and OSX completed
