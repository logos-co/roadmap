Nomos Weekly Update - 2025-08-18 §

Nomos Bedrock §

Research §

  • Cryptoeconomics:

    • Cryptoeconomics of Nomos document ready for review with comprehensive fee markets framework and complete overview section
    • Blockspace Specification adapted to new requirements with storage references removed
    • NomosDA Storage Fee Specifications reviewed
    • CPU confirmed as limiting factor for block construction (except for inscription operations)
    • KPI fee parameter calculation refined to count only Execution base fee and Storage fees as “burned”
    • Reward calculation finalized: DA validators receive DA fees, Leaders receive 40% of KPI tokens and 100% of Execution gas tips

  • Total Stake Inference:

    • Total Stake Inference Analysis enhanced with new plots and expanded convergence analysis
    • Total Stake Inference specification reviews completed with validation
    • Possible directions for future analysis work document created for strategic planning

  • Cryptarchia:

    • Cryptareon: Scalable and Resilient Multi-Proposer Consensus early draft completed for Cryptarchia v2
    • Alternative PPoS mechanisms exploration continued with security analysis

  • Architecture:

    • Bedrock Architecture Overview document ready for review after multiple drafts
    • Wallet Design planning initiated with interface specifications

  • Wallet Standards:

    • Wallet Technical Standard updated to compress keys for increased ZK efficiency
    • Rewards process simplified by tracking values directly in ledger instead of creating special notes

Development §

  • Cryptarchia Core:

    • Offline Grace Period implementation completed as part of bootstrapping feature set
    • IBD multiple downloads improvement merged for better performance
    • Chain service refactoring planned for testability and extensibility (#1505)

  • ZK Components:

    • Groth16 verifier implementation completed with fixes
    • ZK crates restructure consolidating into single subfolder
    • Proof of claim implementation completed
    • CPU cycles measurement test for ZK signature verification added for gas cost calculations
    • Poseidon2 wrapper implementation in progress using custom parameters

  • Ledger and Transaction Processing:

    • Persistent MMR implementation for leader rewards foundation
    • Leader rewards operation implementation with persistent data structures
