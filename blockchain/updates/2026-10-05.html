blockchain:highlights

  • blockchain:bedrock:research:cryptarchia

    • Blend connection traffic bounded at the receiver RFC merged logos-lips#421; connection maintenance tightened after the implementation review: only verified messages count towards a connection’s share, handshake time a core node parameter (draft) logos-lips#468
    • Eras RFC extended: eras can change consensus parameters, transactions and protocol identifiers carry the fork digest (draft) logos-lips#439
    • Strict EdDSA verification gas figures merged logos-lips#464; multi-signature encoding swaps index and signature, merged logos-lips#469; gossip topics clarified in the p2p network document, merged logos-lips#466

  • blockchain:bedrock:research:empowering

    • Retarget bounds and pool funding RFC merged: reward retarget bounded below by ceil(F/(P-F)) and above by its genesis target, pool refilled from a share of fees with the accounting carried through genesis, rewards, and cryptoeconomics logos-lips#443
    • Onboarding model extended so a fraction of mined tokens unlocks immediately, calculator and documentation updated doc; slides summarising model parameters, derived quantities, and assumptions slides
