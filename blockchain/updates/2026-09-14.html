blockchain:bedrock:research

  • blockchain:bedrock:research:cryptarchia

    • Every Operation now carries a proof, with gas independent of it: spec merged logos-lips#431; node verifies the fresh channel config proof and derives execution gas from state, merged #3456
    • Last served epoch made rewardable: RFC merged logos-lips#435, implementation merged #3492, #3493
    • Wallet Technical Standard 1.1.0 merged: key derivation constants and Poseidon2 mode fixed logos-lips#437
    • Blend Failure Detection and Reaction RFC merged logos-lips#412
    • Blend connection traffic RFC moved to review: message budget enforced at the receiver, sized from the node verification rate and shared over connections with a reserve for edge nodes; liveness judged per identity so a reconnect resumes observation (in-review) logos-lips#421
    • Dual-key notes RFC opened: every note commits to a STARK-field public key now, easing the later proof-system transition (in-review) logos-lips#442
    • Mempool transaction retention and maturity RFC opened: retired transactions stay resolvable until release at 2 * TRANSACTION_TTL, block building gated on a maturity age of BLEND_DELAY + BROADCAST_DELAY (in-review) logos-lips#448
    • Blend data messages carry a length-prefixed batch of transactions in one payload (draft) logos-lips#444

  • blockchain:bedrock:research:empowering

    • EmPoWering machinery RFC merged: claims signed with the mined key, tickets ordered with the epoch nonce last, reward pool and difficulty controllers moved into a new Proof of Work document logos-lips#400
    • Follow-up RFCs carved out of the merged machinery: reward retarget floor and pool refill from a fee share (in-review) logos-lips#443; reward puzzle solved with Equi-X against an effort target (draft) logos-lips#447
    • Proof of Work ticket derivation updated to resist mining optimizations #3500; Proof of Quota circuits updated with the new Poseidon2 input order logos-blockchain-circuits#55
    • Most conservative onboarding design analysed: Proof of Work earns non-transferable stake credits towards a sponsored validator position, and sponsored tokens transfer only after satisfactory validator service; economic simulation is straightforward, production integration with Private Proof of Stake significantly harder doc

  • blockchain:bedrock:research:post-quantum

    • Companion document of fix propositions to ease the Post-Quantum ZK migration doc

  • blockchain:bedrock:research:permissionless-channel-sequencing

    • Research started on reducing the blast radius of a malicious zone sequencer set (WIP) doc
